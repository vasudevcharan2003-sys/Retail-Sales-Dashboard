Retail Sales Dashboard

Project Overview

This project demonstrates retail sales analysis using sample data. It focuses on understanding sales performance, product categories, order volume, and monthly sales trends.

Objectives

- Analyze total sales and order volume.
- Compare sales across product categories.
- Track monthly sales trends.
- Understand regional and sales channel performance.

Tools and Technologies

- Microsoft Excel
- Power BI
- Data Visualization
- DAX measures

Dataset

The project uses illustrative sample retail sales data for demonstration purposes.

Key Metrics

- Total Sales
- Total Orders
- Units Sold
- Average Order Value

Project Status

Starter project. The Power BI report can be built using the included sample dataset.
